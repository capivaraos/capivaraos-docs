# Snout

**Ambiente:** GNOME 51 · **Base:** Fedora 45 · **Arquitetura:** x86_64

O Snout é a edição limpa. O GNOME vem **sem modificações de leiaute** — a experiência é a que os desenvolvedores do GNOME projetaram —, com a identidade do CapivaraOS aplicada por cima: ícones, tema, Plymouth e wallpapers.

É a escolha de quem gosta do GNOME como ele é.

## O que vem instalado

- **GNOME 51** em sessão Wayland
- **Firefox** como navegador padrão
- **LibreOffice**, com tradução para português
- **VLC** e **GIMP**
- **Thunderbird** para e-mail
- **Snapper**, para os instantâneos em Btrfs
- **COS Dev Center** e **COS Config Center**, exclusivos do CapivaraOS

## Para desenvolvedores

O [COS Dev Center](../apps/cos-dev.md) abre no primeiro boot: IA local, trilhas de linguagem, ferramentas de dev e GitHub configurado, sem terminal.

## Identidade visual

Extensões curadas, conjunto de ícones próprio e coleção de wallpapers exclusiva — incluindo uma só do Snout. O leiaute do GNOME fica intocado.

## Atualização

A partir da Série 2 o Snout atualiza **sem reinstalar**, pelo GNOME Software ou pelo terminal. Veja [Atualizar o sistema](../atualizar/index.md).
