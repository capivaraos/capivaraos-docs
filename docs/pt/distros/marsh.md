# Marsh

**Ambiente:** KDE Plasma 6.8 · **Base:** Fedora 45 · **Arquitetura:** x86_64

O Marsh é a edição carro-chefe do CapivaraOS. O KDE Plasma oferece um dos ambientes mais personalizáveis do Linux, e o Marsh chega com ele já arrumado: barra de menu global no topo, dock embaixo, tema escuro e a identidade visual do projeto do boot ao desktop.

É a edição com mais recursos e a que pede mais da máquina das três.

## O que vem instalado

- **KDE Plasma 6.8** em sessão Wayland
- **Firefox** como navegador padrão
- **LibreOffice**, com tradução para português
- **VLC** para vídeo e áudio
- **KeePassXC** para senhas
- **Snapper**, para os instantâneos em Btrfs
- **COS Dev Center** e **COS Config Center**, exclusivos do CapivaraOS

## Para desenvolvedores

O [COS Dev Center](../apps/cos-dev.md) abre no primeiro boot e monta a estação: IA local rodando na sua máquina, trilhas de linguagem por usuário, ferramentas de dev e GitHub configurado — sem terminal.

## Identidade visual

Tema, ícones, Plymouth e GRUB coerentes do boot ao desktop, com coleção própria de wallpapers. No Marsh o **wallpaper muda sozinho conforme a hora do dia**.

!!! tip "Trocar entre claro e escuro"
    Alterne pelas **Cores**, nas Configurações do sistema, e não pelo Tema Global — o Tema Global de fábrica do Breeze sobrepõe os nossos ajustes e desfaz parte da identidade.

## Requisitos

Veja [Requisitos de hardware](../instalacao/requisitos.md). O Marsh é o mais exigente dos três; em máquinas mais modestas, o [Pup](pup.md) entrega o mesmo conjunto de ferramentas com um ambiente mais leve.

## Atualização

A partir da Série 2 o Marsh atualiza **sem reinstalar**, de uma versão para outra e de uma série para a seguinte. Veja [Atualizar o sistema](../atualizar/index.md).
