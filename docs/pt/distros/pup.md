# Pup

**Ambiente:** Xfce  
**Perfil:** Leve, confortável em hardware mais modesto

O Pup é a opção para quem quer um sistema ágil sem abrir mão de um ambiente gráfico completo. O Xfce é rápido, estável e consome poucos recursos — perfeito para notebooks mais antigos ou para quem prefere um desktop enxuto.

## O que vem instalado

- Xfce (versão mais recente disponível no Fedora)
- Gerenciador de arquivos Thunar
- Terminal Xfce4-terminal
- Firefox como navegador padrão

## Identidade visual

O Pup aplica o wallpaper e as cores do CapivaraOS ao Xfce, com o painel configurado para uso imediato.
