# Snout

**Ambiente:** GNOME  
**Perfil:** Limpo e direto ao ponto

O Snout usa o GNOME do Fedora sem modificações de layout — o que significa que você recebe o GNOME exatamente como os desenvolvedores conceberam, com as atualizações chegando sem surpresas.

## O que vem instalado

- GNOME (versão mais recente disponível no Fedora)
- Gerenciador de arquivos Nautilus
- Terminal GNOME
- Firefox como navegador padrão

## Identidade visual

O Snout aplica o wallpaper e as cores do CapivaraOS, mantendo o restante do GNOME no padrão upstream.
