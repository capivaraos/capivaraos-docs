# 系统要求

## Marsh (KDE Plasma)

| 组件 | 最低配置 | 推荐配置 |
|---|---|---|
| CPU | 64 位双核 | 64 位四核 |
| 内存 | 2 GB | 4 GB 或以上 |
| 存储空间 | 20 GB | 40 GB 或以上 |
| 显卡 | 支持 3D 加速 | 独立显卡 |

## Pup (Xfce)

| 组件 | 最低配置 | 推荐配置 |
|---|---|---|
| CPU | 64 位单核 | 64 位双核 |
| 内存 | 1 GB | 2 GB 或以上 |
| 存储空间 | 15 GB | 30 GB 或以上 |

## Snout (GNOME)

| 组件 | 最低配置 | 推荐配置 |
|---|---|---|
| CPU | 64 位双核 | 64 位四核 |
| 内存 | 2 GB | 4 GB 或以上 |
| 存储空间 | 20 GB | 40 GB 或以上 |
| 显卡 | 支持 3D 加速 | 独立显卡 |

## 兼容性

CapivaraOS 基于 Fedora，并继承了其硬件兼容性。支持 Intel 和 AMD 处理器，并实验性支持 ARM 架构。

!!! note "Live 模式"
    你可以通过从 USB 驱动器启动来免安装体验 CapivaraOS。在这种情况下，建议至少配备 2 GB 的内存。
