# Snout

**桌面环境：** GNOME  
**版本定位：** 简洁直观

Snout 使用 Fedora 的 GNOME，未对布局进行修改 —— 这意味着你将获得开发者原汁原味设计的 GNOME，更新时也不会带来任何意外。

## 包含内容

- GNOME（Fedora 上可用的最新版本）
- Nautilus 文件管理器
- GNOME Terminal
- Firefox 默认浏览器

## 视觉风格

Snout 应用了 CapivaraOS 的壁纸和配色，而 GNOME 的其余部分则保持上游默认设置。
