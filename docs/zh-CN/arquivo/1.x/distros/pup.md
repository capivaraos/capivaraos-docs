# Pup

**桌面环境：** Xfce  
**版本定位：** 轻量级，非常适合配置一般的硬件

Pup 是为那些希望系统运行快速、又不愿放弃完整图形环境的用户提供的选择。Xfce 响应迅速、稳定且资源占用低 —— 非常适合老款笔记本电脑或任何偏爱轻量级桌面的用户。

## 包含内容

- Xfce（Fedora 上可用的最新版本）
- Thunar 文件管理器
- Xfce4-terminal
- Firefox 默认浏览器

## 视觉风格

Pup 为 Xfce 应用了 CapivaraOS 的壁纸和配色，面板均已开箱即用。
