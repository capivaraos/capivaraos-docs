# Marsh

**桌面环境：** KDE Plasma  
**版本定位：** 功能齐全，高度可定制

Marsh 是专为喜欢掌控环境每一个细节的用户打造的发行版。KDE Plasma 提供了 Linux 桌面中最丰富的定制功能之一 —— 全局菜单、Dock 栏、主题、小组件 —— 所有内容均可配置。

## 包含内容

- KDE Plasma（Fedora 上可用的最新版本）
- Dolphin 文件管理器
- Konsole 终端
- KDE 应用套件（Kate、Gwenview、Spectacle……）
- Firefox 默认浏览器

## 视觉风格

Marsh 预置了 CapivaraOS 的壁纸和配色，并将其应用到了 Plasma 中；应用菜单和 Dock 栏均已开箱即用。
