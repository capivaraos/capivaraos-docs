# 欢迎来到 CapivaraOS 文档

CapivaraOS 是一套来自巴西、基于 Fedora 的 Linux 发行版家族。三个版本各有各的性格，但调性一致：巴西味、好上手，还有水豚当吉祥物。

## 选一个版本

| 发行版 | 桌面环境 | 特点 |
|---|---|---|
| Marsh | KDE Plasma | 功能齐全，高度可定制 |
| Pup | Xfce | 轻巧，配置不高的机器也很顺 |
| Snout | GNOME | 干净直接，不折腾布局 |

## 服务器：Herd by CapivaraOS

需要一台 **服务器**？[**Herd by CapivaraOS**](../../herd/index.md) 是 _headless_（无桌面）产品线，
面向物理机、虚拟机和云 — 自带 Cockpit、加固的安全配置和开箱即用的合规能力。
更多内容参见
[Herd 文档](../../herd/index.md)。
