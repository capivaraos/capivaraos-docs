# 欢迎使用 CapivaraOS 文档

CapivaraOS 是一个基于 Fedora 的 Linux 发行版系列，专为开发者打造：默认安全，内置本地 AI，并且首次启动时即具备完整的开发环境。

本文档涵盖 **Series 2**，其基于 **Fedora 45**。早期版本的文档仍可在[归档](arquivo/1.x/index.md)中查看。

## 选择你的发行版

| 发行版 | 桌面环境 | 版本定位 |
|---|---|---|
| [Marsh](distros/marsh.md) | KDE Plasma 6.8 | 旗舰版，高度可定制 |
| [Pup](distros/pup.md) | Xfce 4.20 | 轻量且快速，同时不牺牲工具集 |
| [Snout](distros/snout.md) | GNOME 51 | 简洁直接，不更改布局 |

这三个版本均附带相同的工具集，以及同样两个专属应用：
[COS Dev Center](apps/cos-dev.md) 和 [COS Config Center](apps/cos-config.md)。

## 服务器：Herd by CapivaraOS

需要**服务器**？[**Herd by CapivaraOS**](herd/index.md) 是面向物理机、虚拟机和云端的 _无头_ 产品线
（无桌面）——开箱即带 Cockpit、强化安全与合规能力。请参阅
[Herd 文档](herd/index.md)。
