# COS Config Center

**COS Config Center** 用图形界面处理九件事，这些事在 Linux 上通常得靠命令行。它是 CapivaraOS 独有的，三个桌面版本都预装了。

要打开它，在应用菜单里找 **COS Config Center** 就行。

只有涉及系统本身的设置才会要管理员密码，而且每次都会先提醒你。

## 软件与驱动

### 编解码器与额外软件仓库

启用 **RPM Fusion** 软件仓库和 **Flathub**，并装上 Fedora 因专利原因默认不能自带的编解码器。视频和音乐"直接就能播放"，靠的就是它。

!!! note "这些是第三方软件仓库"
    RPM Fusion 和 Flathub 由各自的社区维护，不归 CapivaraOS 或 Fedora 管。某些格式在部分国家受专利保护 — 值得确认一下你所在地区适用哪些规定。

## 磁盘与维护

### 释放磁盘空间

列出可以安全清理的东西，分成两份清单：一份在 **你的用户账户** 里（回收站、缩略图、未使用的 Flatpak 运行时、容器镜像），另一份在 **系统** 里、需要密码（已安装的软件包、旧日志、崩溃转储）。

每一项都会先显示占了多少空间，再由你决定。没勾选的东西一律不会删。

### 开机自动挂载磁盘

开机时自动挂载额外的磁盘和分区，不用你手动去改 `/etc/fstab`。

### 系统日志大小

限制系统日志最多能占多少空间，免得它们一直涨、把磁盘塞满。

### 系统检查

一次快速体检：磁盘剩余空间、正在运行的服务、当前用的视频驱动，以及开机以来的错误。

最后它会生成一份 **可粘贴到论坛的报告**，方便你求助时直接用。报告里 **不会** 带上你的名字、计算机名称或网络地址。

## 键盘与语言

### 巴西键盘布局

在 **ABNT2**、**US International** 和 **US** 之间选 — 用 US International 时还能开启按 `'` 再按 `c` 输入 **ç**，这个细节最让用美式键盘写葡萄牙语的人头疼。

同一套布局也能应用到登录界面。

### 语言与格式

把两件通常被绑在一起的事分开：菜单和应用的 **语言**，以及日期、数字、货币的 **格式**。你可以让系统用英文，同时保留巴西的日期和货币格式。

全系统生效，登录界面也一样，注销后重新登录才会起作用。

## 网络与安全

### 防火墙

用大白话说明哪些东西对网络开放 — "在网络上共享文件夹"、"远程终端访问"、"网页服务器" — 而不是甩给你一堆端口号。

还有 **严格模式**：关掉 1024 以上的端口，只放行你亲自打开的那几个。

### 远程访问与网络

改网络里的 **计算机名称**、开关 **SSH 远程访问**、生成你的 **SSH 密钥**，以及配置 **加密 DNS**。

!!! warning "本版本的两个注意事项"
    SSH 密码登录仍然开着 — 我们不会动 `sshd_config`。另外加密 DNS 可能让只存在于你局域网里的名称没法解析；开启后要是有东西突然打不开，切回 "自动"。

## 关于本版本

COS Config Center 随 Series 2 一起发布，版本为 **0.11.x**，这是带着这九个模块的第一个公开版本。1.0.0 会等用过的人反馈之后再来。

**本版本暂不包含：** NVIDIA 驱动（那是 [COS Dev Center](cos-dev.md) 的活）、双系统配置和视频加速。

**系统更新**也不走这里 — 那些归软件中心或 `dnf` 管。参见 [更新系统](../update/index.md)。
