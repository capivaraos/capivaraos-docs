# Web 控制台 (Cockpit)

Herd 自带 **Cockpit**，这是一个基于浏览器的管理面板。你可以查看系统运行状况、管理服务、网络、存储、账户，阅读日志，甚至打开终端 —— 无需安装任何额外软件。

## 访问

在浏览器中打开：

```
https://<server-ip>:9090
```

!!! note "自签名证书"
    首次访问时，浏览器会提示证书（自签名）警告。这在全新安装的服务器上是正常现象 —— 继续访问即可。在生产环境中，你可以在 `/etc/cockpit/ws-certs.d/` 目录下安装你自己的证书。

该服务是**按需**激活的（`cockpit.socket`）：只有当有人访问 9090 端口时它才会启动，而该端口已在防火墙中放行。

## 登录

- 使用**系统用户**及其**密码**登录（与控制台登录相同）。
- Cockpit 默认**禁止 root 用户登录** —— 请使用你创建的（属于 `wheel` 组的）管理员用户。

!!! tip "管理员权限"
    登录后，点击（右上角的）**“开启管理员权限”**并再次输入密码。这将解锁需要特权的操作（安装更新、管理服务、存储等）。

## 功能模块

| 模块 | 用途 |
|---|---|
| **概览 (Overview)** | 运行状况（CPU、内存）、系统标识、时间、主机名 |
| **日志 (Logs)** | 浏览系统日志（按优先级、服务、时间段过滤） |
| **存储 (Storage)** | 磁盘、分区、LVM、文件系统、挂载点 |
| **网络 (Networking)** | 网卡接口、IP、防火墙、绑定/网桥/VLAN |
| **账户 (Accounts)** | 创建/编辑用户、用户组、SSH 密钥、密码过期时间 |
| **服务 (Services)** | 启用/停止/重启 systemd 单元，查看状态 |
| **软件更新 (Software updates)** | 应用安全和系统更新 |
| **终端 (Terminal)** | 直接在浏览器中操作服务器 Shell |

## 安全建议

Cockpit 是一扇强大的管理大门。在面向公网的服务器上，请考虑以下措施：

- 通过 **VPN** 或 **SSH 隧道** 访问它，而不是将 9090 端口直接暴露给公网：
  ```bash
  ssh -L 9090:localhost:9090 user@<ip>
  # 然后在你的电脑上打开 https://localhost:9090
  ```
- 在 `firewalld` 中限制来源（仅允许管理网络访问 9090 端口）。

请参阅[安全与合规](security.md)。
