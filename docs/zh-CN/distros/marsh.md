# Marsh

**桌面环境：** KDE Plasma 6.8 · **基于：** Fedora 45 · **架构：** x86_64

Marsh 是 CapivaraOS 的旗舰版本。KDE Plasma 是 Linux 上最可定制的桌面环境之一，而 Marsh 在发布时已预先配置妥当：顶部全局菜单栏、底部 Dock 栏、深色主题，以及从启动到桌面的全套项目视觉风格。

它是三个版本中功能最丰富的，也是对机器性能要求最高的。

## 预装内容

- 运行于 Wayland 会话的 **KDE Plasma 6.8**
- **Firefox** 默认浏览器
- **LibreOffice**（含葡萄牙语翻译）
- **VLC** 音视频播放器
- **KeePassXC** 密码管理器
- **Snapper**（用于 Btrfs 快照）
- CapivaraOS 专属的 **COS Dev Center** 和 **COS Config Center**

## 面向开发者

[COS Dev Center](../apps/cos-dev.md) 会在首次启动时打开并配置工作站：在你的本地机器上运行本地 AI、按用户配置编程语言环境、配置开发工具和 GitHub —— 全程无需使用终端。

## 视觉风格

从启动到桌面，主题、图标、Plymouth 和 GRUB 风格保持一致，并附带我们自有的壁纸集。在 Marsh 中，**壁纸会随时间推移自动变换**。

!!! tip "切换亮色和暗色模式"
    请通过系统设置中的**颜色**选项进行切换，而不要使用全局主题 —— Breeze 的默认全局主题会覆盖我们的设置，并破坏部分视觉风格。

## 系统要求

请参阅[硬件要求](../installation/requirements.md)。Marsh 是三个版本中最重的；在配置较弱的机器上，[Pup](pup.md) 可以在更轻量的桌面上提供相同的工具集。

## 升级

从 Series 2 开始，Marsh 升级**无需重装**，可以从一个版本升级到下一个版本，也可以从一个系列升级到下一个系列。请参阅[更新系统](../update/index.md)。
