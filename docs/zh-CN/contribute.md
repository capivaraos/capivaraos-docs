# 如何贡献

CapivaraOS 是一个开源项目，欢迎各种形式的帮助。

## 文档

本文档托管在 [capivaraos-docs](https://github.com/capivaraos/capivaraos-docs) 仓库中。要提出修复建议或添加新页面：

1. Fork 该仓库
2. 在 `docs/en/` 目录下编辑或创建 Markdown 文件
3. 提交 Pull Request

## 测试

下载 ISO 镜像，在真实机器或虚拟机上安装，并报告你的发现。你可以在[论坛](https://capivaraos.org)上报告问题，或者在 GitHub 上提交 issue。

## 评价

在 [SourceForge](https://sourceforge.net/projects/capivaraos/) 上发表评价，有助于其他用户发现该项目，并提高社区工作的知名度。

## 社交媒体

分享、评论、展示你的配置。在 [Instagram](https://www.instagram.com/capivaraos/)、[X](https://x.com/CapivaraOS) 和 [YouTube](https://www.youtube.com/@Capivara-OS) 上找到我们。
