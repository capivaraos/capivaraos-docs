# 系统要求

**Series 2** (Fedora 45) 的配置数据。所有三个版本均为 **x86_64** 架构。

## Marsh (KDE Plasma)

| 组件 | 最低配置 | 推荐配置 |
|---|---|---|
| CPU | 64 位双核 | 64 位四核 |
| 内存 | 2 GB | 4 GB 或以上 |
| 存储空间 | 20 GB | 40 GB 或以上 |
| 显卡 | 支持 3D 加速 | 独立显卡 |

## Pup (Xfce)

| 组件 | 最低配置 | 推荐配置 |
|---|---|---|
| CPU | 64 位单核 | 64 位双核 |
| 内存 | 1 GB | 2 GB 或以上 |
| 存储空间 | 15 GB | 30 GB 或以上 |

## Snout (GNOME)

| 组件 | 最低配置 | 推荐配置 |
|---|---|---|
| CPU | 64 位双核 | 64 位四核 |
| 内存 | 2 GB | 4 GB 或以上 |
| 存储空间 | 20 GB | 40 GB 或以上 |
| 显卡 | 支持 3D 加速 | 独立显卡 |

## 兼容性

CapivaraOS 基于 Fedora，并继承了其硬件兼容性。支持 Intel 和 AMD 处理器，并实验性支持 ARM 架构。

!!! note "Live 模式"
    你可以通过从 USB 驱动器启动来免安装体验 CapivaraOS。在这种情况下，建议至少配备 2 GB 的内存。

!!! warning "如果你打算使用本地 AI"
    上面的存储数据涵盖了系统和日常使用。 [COS Dev Center](../apps/cos-dev.md) 中的**本地 AI** 还会额外下载好几个 GB 的数据 —— 请在你预留的空间外，再多加至少 **20 GB**，并且根据你安装的模型，可能还需要更多空间。

!!! tip "为什么使用 Btrfs"
    安装程序默认使用 **Btrfs**。这使得每次跨代升级前自动创建快照成为可能，这也是为什么推荐空间比最低要求更宽裕的原因。
