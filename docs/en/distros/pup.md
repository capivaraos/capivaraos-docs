# Pup

**Desktop:** Xfce  
**Profile:** Lightweight, great on modest hardware

Pup is the option for those who want a fast system without giving up a full graphical environment. Xfce is quick, stable and light on resources — perfect for older laptops or anyone who prefers a lean desktop.

## What's included

- Xfce (latest version available on Fedora)
- Thunar file manager
- Xfce4-terminal
- Firefox as the default browser

## Visual identity

Pup applies the CapivaraOS wallpaper and colors to Xfce, with the panel configured out of the box.
