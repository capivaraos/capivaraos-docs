# Marsh

**Desktop:** KDE Plasma  
**Profile:** Full-featured, highly customizable

Marsh is the distro for those who like control over every detail of their environment. KDE Plasma offers one of the richest customization sets among Linux desktops — global menus, dock, themes, widgets — all configurable.

## What's included

- KDE Plasma (latest version available on Fedora)
- Dolphin file manager
- Konsole terminal
- KDE application suite (Kate, Gwenview, Spectacle…)
- Firefox as the default browser

## Visual identity

Marsh comes with CapivaraOS wallpaper and colors applied to Plasma, with the application menu and dock configured out of the box.
