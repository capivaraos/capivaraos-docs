# Snout

**Desktop:** GNOME 51 · **Base:** Fedora 45 · **Architecture:** x86_64

Snout is the clean edition. GNOME comes **with no layout modifications** — the experience is the one GNOME's developers designed — with the CapivaraOS identity applied on top: icons, theme, Plymouth and wallpapers.

It is the choice for people who like GNOME as it is.

## What ships with it

- **GNOME 51** on a Wayland session
- **Firefox** as the default browser
- **LibreOffice**, with Portuguese translation
- **VLC** and **GIMP**
- **Thunderbird** for email
- **Snapper**, for Btrfs snapshots
- **COS Dev Center** and **COS Config Center**, exclusive to CapivaraOS

## For developers

[COS Dev Center](../apps/cos-dev.md) opens at first boot: local AI, language tracks, dev tools and GitHub configured, with no terminal.

## Visual identity

Curated extensions, an icon set of our own and an exclusive wallpaper collection — including one only Snout has. GNOME's layout is left untouched.

## Upgrading

From Series 2 on, Snout upgrades **without reinstalling**, through GNOME Software or the terminal. See [Updating the system](../update/index.md).
