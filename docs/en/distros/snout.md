# Snout

**Desktop:** GNOME  
**Profile:** Clean and straightforward

Snout uses Fedora's GNOME without layout modifications — which means you get GNOME exactly as the developers intended, with updates arriving without surprises.

## What's included

- GNOME (latest version available on Fedora)
- Nautilus file manager
- GNOME Terminal
- Firefox as the default browser

## Visual identity

Snout applies the CapivaraOS wallpaper and colors, keeping the rest of GNOME at upstream defaults.
